## Featured project: Nexo

[Try the live demo](https://nexoproj.netlify.app/) · [Explore the code](https://github.com/uhmt/nexo-payment-support-lab)

Nexo is a payment-support simulator. It lets you trace a transaction, investigate a failed notification or duplicate event, and document an incident through resolution. It uses fictitious data and does not process real payments.

- **Frontend:** React and TypeScript.
- **Backend and data:** Netlify Functions with PostgreSQL for the hosted demo; Node.js, Express and SQLite for local development.
- **Reliability:** Tests cover payment scenarios, duplicate-event handling, incident resolution and concurrent updates.

I also built an [ASP.NET Core CRUD API](https://github.com/uhmt/asp.net-core-crud-api) while learning C# and backend fundamentals.
